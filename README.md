# Machine-learning-project
Dataset is collected from the official Nifty indices website by keeping index type:equity and subindex: broad market indices and index : NIFTY50 (merged the obtained data as we can only download an year data at once) and contains Date, Open,High,Low and Close values. 

## To run this project
- put csv file in the same folder as of this code file
- run it on the jupyter if available or run using the google colab
